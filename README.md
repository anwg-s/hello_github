# 我的第一个 GitHub 仓库

信息与计算科学专业在读，正在从零开始学习 Git 和 GitHub。

## 关于这个仓库

这是我建的第一个 GitHub 仓库，用来练习最基本的操作流程。

## 已经练习过的内容

- 用 GitHub Desktop 创建仓库，并发布（Publish）到 GitHub
- 修改文件后提交（commit）、推送（push）到 main
- 新建 add_note 分支，改完 README 后通过 Pull Request 合并回 main
- 合并后删除分支，再把改动拉取（pull）回本地

## 仓库里的文件

- hello.py：最基础的一行 Python 脚本，用来验证文件能正常提交和同步
